Request Pipeline Middleware

Middleware Stack

01
ApiKey
Masking
8 regex patterns sanitize API keys in request/response bodies before any logging sees them. Covers Gemini, GitHub, AWS, OpenAI, Anthropic — 36+ key formats.
02
Capture
Original
Snapshots the raw user question into metadata before compression touches it. Ensures eval scores the real question, not the compressed version.
03
Skill
Injector
Detects $trigger tokens ($ponytail, $caveman), strips them from messages, injects skill prompts into system prompt. Multiple triggers per message. Injected before compression.
04
Headroom
Compress
SmartCrusher (JSON), CodeCompressor (AST), CacheAligner (KV-cache). 60–95% token reduction. Compression happens last — after skills are injected.

Evaluation Ragas Scoring

Quality Scoring

Weight 0.3
Faithfulness
Is the answer grounded in retrieved context? Prevents hallucination. Skipped when no context is available.
Weight 0.3
Answer Relevancy
Does the answer actually address the question? Always scored — the only metric available for context-free calls.
Weight 0.2
Context Precision
Is every piece of retrieved context actually useful? Eliminates noise from over-fetched context.
Weight 0.2
Context Recall
Does the answer cover everything in the context? Requires ground truth. Skipped when unavailable.
