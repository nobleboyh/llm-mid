# Eliminate Idle `/health` LLM Probes — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stop `/health` and LiteLLM's background loop from issuing live, billed provider completions — zero idle probes.

**Architecture:** Two LiteLLM settings work together. `general_settings.background_health_checks: true` makes `GET /health` serve cached `health_check_results` instead of live-probing every deployment on each call. `model_info.disable_background_health_check: true` on every deployment empties the background loop's probe set (`model_count_enabled=0`), so the loop still runs and populates the cache (empty healthy/unhealthy lists → `/health` stays 200) but never calls a provider. Docker's healthcheck and the `gateway_ready` fixture keep working. Routing reverts to failure-cooldown (`allowed_fails`/`cooldown_time`) + existing `router_settings.fallbacks`.

**Tech Stack:** YAML config files, bash generator (`quick-setup.sh`), pytest + PyYAML for the config guard test.

## Global Constraints

- Settings live under `general_settings`, **not** `litellm_settings` (verified at `litellm/proxy/proxy_server.py:4483`, litellm 1.92.0).
- `background_health_checks: true` is required **and** `disable_background_health_check: true` on every deployment — either alone is insufficient for zero probes.
- `litellm_config.yaml` (live) is gitignored and generated by `quick-setup.sh`; config is bind-mounted so fixes apply via `docker compose restart litellm`, no rebuild.
- `quick-setup.sh` must emit a single `model_info:` YAML map per deployment — a map cannot have two `model_info` keys (the `copilot-codex` `mode: responses` block must merge).
- Deployment counts: example config = 10, test config = 8.
- Follow existing test style: plain pytest unit tests, no Docker needed (see `tests/test_local_provider_failure.py`).

- [ ] **Step 1: Write the test**

```python
"""Guard tests: no deployment may trigger live LLM probes from /health.

Enforces the init-007 fix — every deployment must carry
model_info.disable_background_health_check: true AND general_settings must
have background_health_checks: true. Without either, /health or the
background loop issues real billed completions.
"""

import pathlib

import pytest
import yaml

ROOT = pathlib.Path(__file__).resolve().parent.parent
CONFIGS = ["litellm_config.example.yaml", "litellm_config.test.yaml"]


@pytest.mark.parametrize("config_name", CONFIGS)
def test_background_health_checks_enabled(config_name):
    config = yaml.safe_load((ROOT / config_name).read_text())
    gs = config.get("general_settings", {})
    assert gs.get("background_health_checks") is True, (
        f"{config_name}: general_settings.background_health_checks must be true"
    )


@pytest.mark.parametrize("config_name", CONFIGS)
def test_no_deployment_live_probes(config_name):
    config = yaml.safe_load((ROOT / config_name).read_text())
    deployments = config.get("model_list", [])
    assert deployments, f"{config_name}: model_list must be non-empty"
    for dep in deployments:
        name = dep.get("model_name", "<unnamed>")
        mi = dep.get("model_info") or {}
        assert mi.get("disable_background_health_check") is True, (
            f"{config_name}: deployment '{name}' must set "
            "model_info.disable_background_health_check: true"
        )
```
